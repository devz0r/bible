# Key-Term Glossary

Default English renderings for theologically and lexically important words. Governed by the [charter](charter.md) §3.4 (concordance).

**How to use this:**
- **Default** is used unless context clearly requires another sense.
- **Context renderings** are approved alternatives. When one is used, add a note at its first occurrence in each book, unless the sense is obvious (for example, *kyrios* = "sir" in conversation).
- **First-note** means the term gets an explanatory note at its first occurrence in each book.
- A departure from this list that is not covered here must be recorded in the charter's decision log, and the glossary must be updated.
- Strong's numbers are for cross-reference only. Meanings are decided from context and the scholarly lexicons.

**Status:** Draft 1, 2026-11-03. This is the core list. It will grow to about 200 entries as translation proceeds.
