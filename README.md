# The Transparent Bible (working title)

An English translation of the Bible from the original Hebrew, Aramaic and Greek that aims to be:

- **Accurate:** faithful to the words and meaning of the originals.
- **Readable:** plain modern English, with no *thee*, *thou* or *-eth*.
- **Transparent:** nothing hidden. Words the translator added are marked, as in the KJV's italics. Plural "you" is marked, recovering the KJV's *ye/thee* distinction. Manuscript differences are footnoted candidly. Wherever a word has more than one meaning in play, the alternatives are shown.

## Key decisions

| | |
|---|---|
| New Testament text | Textus Receptus (the Greek behind the KJV), with critical-text and Majority-text readings in footnotes |
| Old Testament text | Masoretic Text, with Dead Sea Scrolls and Septuagint readings in footnotes |
| Divine name | LORD (small capitals) |
| Books | The 66-book Protestant canon (the Apocrypha may be added later as a separate section) |
| Gender language | Not gender-inclusive: masculine forms are translated as masculine |
| License | Public domain (CC0) |
